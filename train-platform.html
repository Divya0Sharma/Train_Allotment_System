HOW IT WORKS

Sorts all trains by arrival time, then iterates through the schedule. For each train, the min-heap reveals the earliest available platform. If that platform is free before the current arrival, it's reused. Otherwise, a new platform is spawned.

01 Sort all trains by arrival time in ascending order.
02 Push first train's departure time onto the min-heap.
03 For each subsequent train: if heap's minimum ≤ arrival, pop and reuse that platform.
04 Otherwise, allocate a new platform. Push departure time to heap.
05 Heap size at any point = platforms currently in use. Max size = minimum platforms required.
platform_allotment.cpp 
// Train Platform Allotment System
// Greedy Algorithm + Min-Heap PQ

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

struct Train {
    int arrival, departure;
};

int minPlatforms(vector<Train>& trains) {
    // Sort by arrival time
    sort(trains.begin(), trains.end(),
        [](const Train& a, const Train& b) {
            return a.arrival < b.arrival;
        });

    // Min-Heap: tracks departure times
    priority_queue<int, vector<int>,
        greater<int>> minHeap;

    int maxPlatforms = 0;

    for (auto& train : trains) {
        // Free platform if available
        if (!minHeap.empty() &&
            minHeap.top() <= train.arrival)
            minHeap.pop();

        minHeap.push(train.departure);
        maxPlatforms = max(maxPlatforms,
            (int)minHeap.size());
    }
    return maxPlatforms;
}
